🤝 03.1 认识信令服务器：一个只管转交 JSON 名片的「传话人」

进入五步全景图的第 ② 步（信令互换名片）与第 ③ 步（候选地址传递）：WebRTC 规范之所以故意不内置信令协议，是因为不同业务有截然不同的进房前逻辑——1v1 社交有「左滑右滑随机匹配池」、企业会议有「密码入会与主持人准入」、付费咨询有「余额校验」。WebRTC 把这部分完全交由业务自己的后端（通常用 WebSocket）控制。

从代码层面看，一个双人 WebRTC 信令服务器做的事情非常单纯：维护房间里的两个 WebSocket 连接，把 A 发来的 JSON 原封不动转发给同房间的 B，完全不触碰任何音视频字节：

🟢 signaling-server.mjs · 35 行最小房间转发信令服务（npm i ws） 
import { WebSocketServer } from 'ws';

const wss = new WebSocketServer({ port: 8080 });
// roomId -> Set<WebSocket> 保存每个房间内的在线客户端
const rooms = new Map();

wss.on('connection', ws => {
  ws.on('message', raw => {
    const msg = JSON.parse(raw.toString());
    const { roomId, type, payload } = msg;

    if (type === 'join') {
      if (!rooms.has(roomId)) rooms.set(roomId, new Set());
      const peers = rooms.get(roomId);
      peers.add(ws);
      ws.roomId = roomId;
      // 当第二个用户进房时，通知先在房里的用户担任 Caller 发起呼叫
      if (peers.size === 2) {
        const [caller] = peers;
        caller.send(JSON.stringify({ type: 'peer-ready' }));
      }
      return;
    }

    // 其余消息（offer / answer / ice-candidate）直接转发给同房间对端
    const peers = rooms.get(roomId) || [];
    for (const client of peers) {
      if (client !== ws && client.readyState === 1) {
        client.send(JSON.stringify({ type, payload }));
      }
    }
  });

  ws.on('close', () => rooms.get(ws.roomId)?.delete(ws));
});
📋 信令信道里实际只传递这 4 类轻量消息
  • join / peer-ready（房间匹配控制）：决定谁和谁配成一对，并指定其中一方担任主叫方（Caller）主动发起 createOffer()，避免两人同时发 Offer 撞车。
  • offer（主叫方的 SDP 能力名片）：主叫方生成自己的编解码与加密描述，设为本地描述（setLocalDescription）后发给被叫方。
  • answer（被叫方的 SDP 应答名片）：被叫方收下主叫方名片（setRemoteDescription），生成兼容的交集名片设为本地描述并回传给主叫方。
  • ice-candidate（增量网络候选路线）：双方浏览器在后台一边向 STUN/TURN 探测可用 IP:Port，一边触发 onicecandidate 通过信令发给对方，对方收到后调用 addIceCandidate 尝试打洞连通。

除了音视频轨道之外，RTCPeerConnection 还附带了一个非常实用的能力——RTCDataChannel（端到端数据通道）。它复用已经打通的同一条 P2P 连接，让你像写 WebSocket 一样直接在两个浏览器之间收发任意 JSON 文本或二进制 ArrayBuffer（例如视频聊天时发送点赞爱心动效坐标、实时翻译双语字幕、点对点传文件）：

🟦 TypeScript · 在同一条连接上开启 RTCDataChannel 收发低延迟互动指令或字幕 
// 【主叫方 Caller】在调用 createOffer() 之前主动创建一条数据通道（这样通道描述会自动写进 Offer SDP）
const chatChannel = pc.createDataChannel('social-events', {
  ordered: true, // true: 像 TCP 一样保序可靠（适合文字聊天/工具指令）；false + maxRetransmits:0 适合极低延迟高频坐标同步
});
chatChannel.onopen = () => {
  chatChannel.send(JSON.stringify({ type: 'gift-effect', giftId: 'rose' }));
};

// 【被叫方 Callee】通过 pc.ondatachannel 接收对端建立的数据通道
pc.ondatachannel = event => {
  const recvChannel = event.channel;
  recvChannel.onmessage = e => {
    const data = JSON.parse(e.data);
    console.log('收到对端实时互动事件:', data);
  };
};
