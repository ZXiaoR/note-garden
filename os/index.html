00 · 第一性原理导读：为什么要学操作系统？入门懂什么、进阶在解决什么？

从裸机运行程序的三大困境（CPU 独占失控、物理内存互踩与不足、慢速 I/O 阻塞 CPU）出发，推导操作系统「进程/线程虚拟化、虚拟内存页表、文件与多路复用 I/O、并发同步与 IPC」四大主线。

01 · 特权与入口：OS 在管什么、用户态 Ring 3 / 内核态 Ring 0、syscall 与中断上下半部

涵盖宏内核 vs 微内核、Ring 3 进入 Ring 0 的唯一三条路径（系统调用 syscall、异常 Exception、外部硬件中断 Interrupt）、模式切换 vs 上下文切换、vDSO 零陷入机制，以及 Linux 硬中断上半部与软中断下半部（softirq / tasklet / workqueue）。

02 · 执行实体：进程与 PCB (task_struct)、状态转换 (R/S/D/Z/T)、线程与协程、写时复制 COW

涵盖 64 位虚拟地址空间布局与 KPTI 页表隔离、僵尸进程 Z 与不可中断睡眠 D（含 TASK_KILLABLE）排查、进程 vs 内核线程 vs 用户态协程三维对比、跨进程切换刷 TLB 成本，以及 fork() 写时复制（COW）与透明大页 THP 在 Redis RDB 下的延迟影响。

03 · 内存管理：存储层次与 64B 缓存行伪共享、虚拟内存、x86-64 四级页表与 TLB、缺页置换与 Buddy/Slab/malloc

涵盖存储金字塔延迟、64B Cache Line 伪共享与 MESI、分段 vs 分页、48 位地址 9+9+9+9+12 四级页表与 TLB 快表、延迟分配（Lazy Allocation）与次缺页/主缺页、Linux 双链表 LRU，以及内核 Buddy/Slub 与用户态 malloc（初始 128KB 动态至 32MB 的 brk/mmap 阈值）和 VIRT/RES/PSS/OOM。

04 · 进程间通信 IPC：匿名管道 Pipe、命名管道 FIFO、消息队列、共享内存、信号量、Signal 与 Socket

涵盖内核中转 IPC（2 次拷贝）与共享内存（0 次内核拷贝，最快 IPC）对比、eventfd/timerfd/signalfd、SIGTERM(15) 优雅退出 vs SIGKILL(9) 强制终止、SIGPIPE 防护、信号处理函数异步信号安全铁律，以及 Unix Domain Socket（SCM_RIGHTS 传递 fd）。

05 · 并发与同步：竞态与并发三要素、Mutex / 自旋锁 / 条件变量、CAS 与 ABA、Linux futex 与死锁防治

涵盖原子性/可见性/有序性、互斥锁 vs 自旋锁适用边界、pthread_cond_wait 用 while 防虚假唤醒、硬件 CAS 与版本号解 ABA、Linux futex 用户态快路径、生产者消费者信号量顺序，以及死锁四大必要条件、固定加锁顺序破环与优先级反转（优先级继承）。

06 · CPU 调度：周转时间 vs 响应时间、抢占时机 (TIF_NEED_RESCHED)、MLFQ、Linux CFS 与 EEVDF

涵盖 FCFS / SJF / Priority / RR / 多级反馈队列（MLFQ）演进、Linux CFS 权重归一化虚拟运行时间 vruntime 与红黑树 rb_root_cached $O(1)$ 取最左节点、min_vruntime 睡眠补偿、Linux 6.6+ EEVDF 虚拟截止时间调度，以及 K8s 容器 cgroup v2 cpu.max 限流与 Go 1.25+ 原生容器配额感知。

07 · 文件与高性能 I/O：VFS / inode / 内核三张表、Page Cache 与 fsync/O_DIRECT、epoll / Reactor / io_uring 与零拷贝

涵盖目录项 dentry 与 inode、硬链接 vs 软链接、rm 后未释放句柄排查（lsof +L1）、进程 fd 表 → 系统打开文件表 → inode 表、Page Cache 脏页回写与 MySQL O_DIRECT、五种 I/O 模型、select/poll/epoll 红黑树+就绪链表、LT vs ET（Redis LT / Go & Netty native epoll ET）、三种 Reactor 模型与 mmap / sendfile + SG-DMA 零拷贝。

08 · Linux 常用命令与实战：文件权限 (rwx/SUID/Sticky) 与查找、文本三剑客 (grep/awk/sed)、网络抓包 (ss/tcpdump/curl) 与后台守护

涵盖普通文件 vs 目录 rwx 权限差异、SUID/Sticky Bit/umask、find/xargs/tar/rsync、grep/awk/sed/sort/uniq 日志 Top K 统计一行流、ss -tulpn vs netstat、tcpdump 抓包与 curl -w 耗时拆解、nohup ... > app.log 2>&1 & 重定向顺序原理与 /proc 虚拟文件系统。

09 · 全链路串联与排查：./a.out 运行 6 步内核旅程、Linux 线上性能排障 SOP、20 题速记表与 8 题闭卷自测

串联 fork(COW) → CFS/EEVDF 调度上 CPU → execve 重建 VMA → 缺页异常与 TLB → malloc/futex/epoll → exit_group 与父进程 wait4 回收 全流程，详解 load average vs CPU%、free -h available、vmstat/pidstat/perf/strace/iostat 排障命令集与高频面试自测问答。
