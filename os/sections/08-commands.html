08Linux 第一次上手 · 终端、目录、文件与软件安装 从第一条命令开始
🧭 第一次面对“黑框框”，从这里开始。

这一章假设你刚打开终端，或刚登录一台 Linux 服务器。先学会看自己在哪、进出文件夹、打开一个文件，再按需要学习安装软件、上传下载和解压。

第一次只练 08.1—08.3 就够了。后面三节遇到对应任务时再看；不需要一次记住全部命令，也不需要先读懂前面的内核原理。
❓ 光标在闪，我应该把什么输进去？

⌨️ 08.1 先敲一条不会修改文件的命令

终端就是用文字向电脑发出操作请求的窗口。你输入一条命令，按回车，系统执行后显示结果，然后等下一条。有 Linux 桌面就打开“终端”；如果是服务器，先用已配置好的 SSH 连接登录。下面的 Linux 命令都在这个窗口里输入。

屏幕示意 · 只输入 pwd，不要复制前面的提示符
alice@server:~$ pwd
/home/alice
alice@server:~$

第一行末尾的 pwd 是你输入的命令，意思是“显示当前目录”。第二行 /home/alice 是系统的回答。第三行重新出现提示符，表示它执行完了，正在等你。用户名和机器名会因环境不同而变化。

后面的命令框只放要输入的内容。一次输入一行，按回车，再看结果。很多命令成功后没有文字输出，直接回到提示符也是正常的。
  • 还没按回车：可以用退格改字；想清掉当前输入，在常见 Shell 中可按 Ctrl + U。
  • 正在运行，想停下来：通常按 Ctrl + C。如果只是分页看文件，用 q 退出。
  • 路径太长：输入前几个字母按 Tab 尝试补全；按 ↑ 可以找上一条命令。
📎 还没连接服务器？本机窗口和服务器窗口有什么区别？

在自己电脑的终端输入 SSH 连接命令后，才会进入远程 Linux。登录后的命令操作的是服务器；另外打开的本机终端仍操作自己的电脑。Windows 也可以在 PowerShell 中使用已安装的 OpenSSH 客户端。

在自己电脑上输入 · 将示例账号和地址换成实际值
ssh alice@192.0.2.10

alice 是服务器账号，192.0.2.10 是示意地址。账号、地址、端口和登录方式由服务器提供方告知；首次连接时核对主机指纹。输入密码时通常不显示字符或星号，这不代表键盘没反应。退出远程登录可输入 exit。

❓ 没有“我的电脑”和盘符，去哪里找文件？

📂 08.2 我在哪？文件夹里有什么？

Linux 也有文件夹，命令里通常叫目录。先记住三个动作：pwd 看当前位置，ls 看里面有什么，cd 换到另一个目录。cd 只改变位置，不会移动文件。

在 Linux 终端逐行输入 · 先回到自己的主目录
cd ~
pwd
ls

~ 表示当前用户的主目录，可以把它理解成“自己的文件夹”。普通账号常见路径是 /home/alice；root 账号通常是 /root。ls 没有输出，也可能只是这个目录里暂时没有可显示的文件。

建一个练习文件夹，再走进去
mkdir linux-practice
cd linux-practice
pwd

mkdir 创建目录。最后通常会看到类似 /home/alice/linux-practice 的路径，说明你已走进练习目录。如果提示目录已存在，直接 cd linux-practice 即可。

两个回去的方法：cd .. 回上一级；cd ~ 回主目录。. 是当前目录，.. 是它的上一级。
📎 认识常见目录 · 先知道用途，不必背整棵树
路径可以怎样理解
/整个目录树的起点，叫根目录；与 root 用户的主目录 /root 不是一回事。
/home普通用户的主目录通常放在这里。练习和上传文件先放自己的主目录。
/etc系统和软件的配置文件，暂时只认识，不需要修改。
/var/log很多系统与软件的日志；不同系统也可能用其他方式存日志。
/tmp临时文件，可能被系统清理，不适合保存重要资料。
/usr/bin很多安装好的命令所在的位置，通常不用自己往里面放文件。

/home/alice/hello.txt 从根目录开始，是绝对路径；hello.txt 从你所在目录找，是相对路径。Linux 区分大小写，Hello.txt 与 hello.txt 是不同名字。

❓ 敲了 cat 以后看到的是什么？怎样退出？

📄 08.3 创建一个小文件，再把它打开

接着留在 linux-practice 目录里。先创建一个只有一行文字的练习文件，再查看它：

创建并查看 hello.txt · 两行分别执行
printf 'hello linux\n' > hello.txt
cat hello.txt

printf 输出文字，> hello.txt 把文字写进文件， 表示换行。这条命令会覆盖同名文件的旧内容，所以只对自己的练习文件使用。cat 把文件内容显示在终端中；这里应该看到 hello linux。

文件比较长时，改用分页阅读
less hello.txt

进入 less 后，方向键上下移动，空格翻页，按 q 退出，回到命令提示符。它是查看器，这样阅读不会修改文件。若提示找不到 less，可以先用 cat，或按下一节安装。

练到这里就可以停下：你已经会定位目录、创建文件夹、写入一行文字并查看文件。先重复一遍，熟悉“输入 → 回车 → 看结果”。
📎 需要复制、改名或删除文件时，再学这三个动作
仍在练习目录 · 每次只执行需要的一行
cp hello.txt hello-copy.txt
mv hello-copy.txt notes.txt
rm -i notes.txt

cp 复制，原文件还在；mv 在这个例子里改名，也可以移动文件。目标同名时可能覆盖已有文件。rm -i 删除前询问，确认后输入 y；不删除输入 n。命令行删除通常不经过桌面回收站。

想看文件大小可用 ls -lh；想包含点开头的隐藏文件，用 ls -a。文件名含空格时，用引号包住，例如 cat "my notes.txt"。

❓ 为什么别人敲 apt 可以，我这里却找不到？

📦 08.4 软件怎么安装？先看自己用的是什么系统

Linux 有 Ubuntu、Debian、Fedora 等不同发行版，安装软件的工具可能不同。软件仓库可以理解成系统配置好的软件下载来源，包管理器负责下载、安装以及处理依赖。

在 Linux 上查看发行版 · 只读取系统信息
cat /etc/os-release

看输出中的 NAME 或 ID。下面只选与你的系统对应的一组，不要两组都执行。如果服务器有团队指定的安装方式，以那份说明为准。

📎 Ubuntu / Debian：用 apt 安装文件查看工具 less
安装操作 · 需要账号拥有 sudo 权限
sudo apt update
sudo apt install less

第一行更新“可安装软件列表”，不是升级整个系统；第二行下载并安装 less。如果询问是否继续，看清要安装的内容，再输入 y 回车。完成后就能执行 less hello.txt。

📎 Fedora / 常见较新 RHEL 系发行版：用 dnf
安装操作 · 需要账号拥有 sudo 权限
sudo dnf install less

这条命令安装同一个文件查看工具。老系统可能提供 yum；如果 dnf 不存在，先查该发行版的安装说明，不要反复换命令尝试。

sudo 是什么意思？它让获准的账号以管理员权限执行这一条命令，可能要求输入当前账号密码。密码不回显是正常现象；权限不足时需要管理员协助。平时的 cd、ls、cat 不必习惯性加 sudo。

下载安装包 ≠ 安装完成。仓库里的软件优先按上述方式安装；从官网下载的 .deb、.rpm 或压缩包，处理方式各不相同，按该软件自己的安装说明继续。

❓ 我电脑上的包，怎么传到服务器？

↕️ 08.5 上传、下载，先分清文件从哪到哪

上传：自己的电脑 → 服务器。下载到本机：服务器 → 自己的电脑。如果 SSH 工具有 SFTP 文件面板，也可以选中文件传输；先确认本机与服务器两边显示的目录。

下面的 scp 命令在自己电脑的新终端窗口里敲，不是在已经登录服务器的窗口里敲。Windows 可使用已安装 OpenSSH 的 PowerShell，macOS / Linux 可使用本机终端。

假设本机当前目录有 demo.tar.gz。把示例中的账号 alice 和地址 192.0.2.10 换成你的服务器信息：

本机执行 · 把安装包上传到服务器的主目录
scp demo.tar.gz alice@192.0.2.10:~/

scp 后面按顺序写“从哪里复制”“复制到哪里”。账号@地址: 表示远程机器，~/ 是远程账号的主目录。传完后回到服务器窗口，执行 ls ~，检查文件是否出现。

📎 反过来：把服务器上的文件下载到自己电脑
本机执行 · 把服务器主目录里的包下载到当前目录
scp alice@192.0.2.10:~/demo.tar.gz .

这里把来源与目标对调。最后的 . 指本机当前目录。若服务器使用指定端口，例如 2222，写成 scp -P 2222 ...；这里是大写 P。

📎 另一种“下载”：让服务器从网址保存文件
Linux 上执行 · 先下载一个小网页练习，不是软件安装包
cd ~/linux-practice
curl -fL https://example.com/ -o page.html
ls -lh page.html

文件会保存在执行 curl 的那台机器。-o page.html 指定保存的文件名，-L 跟随网址跳转，-f 让常见 HTTP 错误以失败返回。下载真正的软件包时，用软件官网给出的地址与对应文件名；保存网页并不等于安装软件。curl 不存在时，可按上一节用系统包管理器安装 curl。

❓ tar.gz 和 zip 分别怎么解压？

🗜️ 08.6 收到压缩包后，怎么打开？

先看文件名后缀。.tar 通常是把一组文件打成包；.tar.gz 在打包后又做了压缩；.zip 是另一种常见格式。解压只是把文件展开，还不代表软件已经安装。

下面用刚才的练习文件夹做一个自己的包。先回主目录，把它打包：

Linux 上执行 · 在主目录生成 linux-practice.tar.gz
cd ~
tar -czf linux-practice.tar.gz linux-practice

linux-practice.tar.gz 是生成的包名，后面的 linux-practice 是要打包的目录。原目录仍然保留。c 表示创建，z 表示 gzip 压缩，f 表示后面跟包的文件名。

解压到新目录，方便看清展开了什么
mkdir unpacked
tar -xzf linux-practice.tar.gz -C unpacked
ls unpacked

x 表示解开，-C unpacked 指定展开到哪里，该目录要先存在。你应该在 unpacked 里看到 linux-practice 文件夹。已有 unpacked 时不用重复 mkdir；解压同名内容可能覆盖文件，练习时使用空目录。

📎 收到的是 .zip 文件怎么办？
替换成实际的 zip 文件名 · 单独解压到 zip-output 目录
unzip demo.zip -d zip-output

-d 指定解压目录。unzip 不存在时，用上一节介绍的包管理器安装 unzip。若要自己生成 zip，可安装 zip 后执行 zip -r practice.zip linux-practice，其中 -r 表示把目录里的内容一起打包。

现在可以完成一条小流程：建文件夹 → 写一个文件 → 查看内容 → 打包 → 在另一个目录解开。安装软件、上传和下载则在需要时再查，不必一次全练完。
