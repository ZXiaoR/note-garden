消息队列 · 基础与实战篇：全景定位、快速上手、七大场景与防丢规范

面向从未接触过消息队列的开发者与日常工程复习：以 Kafka（KRaft 模式）为主线、Go 代码为核心，一屏讲清消息队列在系统中的分层位置与适用边界，五分钟在本地跑通收发与消费组实验，逐个落地异步通知、秒杀削峰、日志采集、数据同步、本地消息表、延迟关单与死信重试七大通用业务场景，最后配齐三段防丢、消费幂等、局部保序、积压排障、三大主流选型与上线前必知清单。

00 · 全景科普：消息队列架构定位、场景地图与适用边界

一句话定义与快递驿站类比、电商下单引入 MQ 前后对比图、七大通用业务场景地图、不适用边界与三大代价、四方对比表及全篇知识地图。

01 · 核心概念：六大基础组件与消费者组统一模型

一张图串起 Producer、Broker、Topic、Partition、Offset 与 Consumer Group，掌握「组内竞争、组间广播」与「消费者数 ≤ 分区数」设计约束。

02 · 跑起来：Docker 启动 Kafka（KRaft）、命令行与第一段收发代码

Docker Compose 启动单节点 Kafka 3.8 与 Web UI、命令行建 Topic/收发/看 Lag、Go 与 Node.js 最小示例，以及同组竞争与跨组广播动手实验。

03 · 常见实战场景：按需求落地的七套消息队列方案

按「需求 → 为什么用 MQ → 设计 → Go 代码 → 常见坑 → 背后原理」逐个实现下单发券通知、秒杀削峰与耗时任务排队、日志批量压缩、异构数据同步、本地消息表（对比 RocketMQ 事务）、延迟关单与阶梯重试死信队列。

04 · 不丢与不重：三段防丢配置、手动提交与消费端幂等代码

给出生产端、Broker、消费端防丢配置与手动提交 Offset 代码，提供数据库唯一索引、状态机条件更新、Redis SET NX 状态机三段幂等代码及 EOS 适用结论。

05 · 顺序与积压：同单号局部保序代码与线上积压排障命令

用订单号作 Key 实现单分区局部有序消费，汇总查看 Lag、定位消费卡死或慢调用、常规加实例与临时 10 倍分区 Topic 紧急泄洪实战流程。

06 · 三大 MQ 选型：Kafka、RocketMQ、RabbitMQ 与 Redis Stream 边界

拆解三大主流 MQ 架构差异与 RabbitMQ 四种交换机路由规则，通过多维选型表给出何时选哪款及何时 Redis Stream 已够用的明确结论。

07 · 上线前必须知道：Topic 规范、消息兼容、防踢调参与监控告警

梳理 Topic 命名与分区估算、消息大小与字段向后兼容、max.poll.interval.ms 超时防踢出消费组、重试/DLQ/幂等核查与五项核心监控指标。

串联订单消息全生命周期，以默认折叠的真实故障题检验重复发券、状态乱序、百万积压、丢消息等排障思路，附 15 题一句话速记表。
