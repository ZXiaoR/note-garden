02.1 · 变量与常量：var / := 声明方式、零值默认值与 const / iota

02.1 变量声明、默认零值与常量枚举（const / iota）

变量的四种声明方式与“零值”设计：在 Go 中声明变量有四种常见写法。与 JavaScript 未赋值变量为 undefined 不同，Go 保证任何声明后未显式赋初值的变量，都会自动赋予该类型的“零值（Zero Value）”，不会出现未初始化的脏数据：

vars.go · 四种变量声明写法与零值 [Go 1.22+] 
package main

import "fmt"

// 函数外部（包级变量）必须使用 var 关键字声明，不能用 :=
var appVersion = "1.0.0"

func main() {
    var a int = 10   // 1. 完整声明：显式写出类型与初始值
    var b = 20       // 2. 类型推导：省略类型，编译器自动推导为 int
    c := 30          // 3. 短变量声明（函数内最常用）：声明并直接赋值

    // 4. 零值声明：只声明不赋值，自动获得该类型的安全零值
    var count int    // 数值型零值: 0
    var title string // 字符串零值: "" (空字符串)
    var ready bool   // 布尔型零值: false

    fmt.Println(appVersion, a, b, c, count, title == "", ready)
    // 输出: 1.0.0 10 20 30 0 true false
}
const_iota.go · 常量与 iota 自动递增枚举 [Go 1.22+] 
package main

import "fmt"

// 使用 const (...) 块配合 iota 定义连续枚举值：
// 每个 const 块内，iota 从第 0 行起初始为 0，每往下一行自动 +1
const (
    StatusPending = iota // 第 0 行: iota = 0
    StatusRunning        // 第 1 行: 沿用上一行表达式，iota = 1
    StatusSuccess        // 第 2 行: iota = 2
    StatusFailed         // 第 3 行: iota = 3
)

// 配合左移位运算 1 << iota 定义权限位掩码（1, 2, 4...）：
const (
    PermRead  = 1 << iota // 1 << 0 = 1 (二进制 001)
    PermWrite             // 1 << 1 = 2 (二进制 010)
    PermExec              // 1 << 2 = 4 (二进制 100)
)

func main() {
    fmt.Println(StatusPending, StatusSuccess, PermRead|PermWrite) // 0 2 3
}

02.2 基础数据类型全览：布尔、整数、浮点数与类型转换

JavaScript 只有一个笼统的 number 类型（底层为 64 位浮点数），而 Go 将数值精细拆分为不同位宽的有符号整数、无符号整数与浮点数。下表汇总了日常开发中的选型原则：

显式类型转换规则：为了防止混合运算时悄悄丢失精度，Go 没有任何隐式数值转换——哪怕是 int 和 int64 相加，也必须写成 目标类型(变量) 显式转换后再算：

number_convert.go · 显式类型转换与整数相除注意项 [Go 1.22+] 
package main

import "fmt"

func main() {
    var count int = 10
    var total int64 = 1000

    // 1. 不同整数类型相加，必须用 int64(count) 显式转换，否则编译报错
    sum := int64(count) + total

    // 2. 两个整数直接相除会截断小数部分（3 / 10 == 0），求比例前先转 float64
    rate := float64(3) / float64(count)

    fmt.Println(sum, rate) // 输出: 1010 0.3
}
02.3 · 字符与字符串：byte / rune / string 关系与日常字符串操作大全

02.3 字符与字符串：byte / rune / string 的日常用法

在 Go 中，字符串底层默认按 UTF-8 字节存储——英文字符和数字每个占 1 字节，常用中文汉字每个占 3 字节。因此写业务时需要区分“按字节算”还是“按字符个数算”：

  • len(s) 返回的是底层字节数，不是字符个数；统计含中文的字数用 utf8.RuneCountInString(s)，按字截取先转为 []rune(s)；
  • 双引号 vs 反引号：双引号 "Hello\n" 解析转义符；反引号 `...` 原样保留换行和引号（非常适合写多行 SQL 与 JSON 模板，但不像 JS 模板字符串那样支持 ${x} 插值，格式化拼接用 fmt.Sprintf）。
string_len_sub.go · 求字数、遍历与含中文安全截取 [Go 1.22+] 
package main

import (
    "fmt"
    "unicode/utf8"
)

func main() {
    s := "Go语言" // 'G'(1B) + 'o'(1B) + '语'(3B) + '言'(3B)

    // 1. len(s) 是字节数 8；实际字符个数用 RuneCountInString 得到 4
    fmt.Println(len(s), utf8.RuneCountInString(s)) // 8 4

    // 2. for range 遍历字符串时，自动按完整字符 (rune) 解码，不会截出半个乱码汉字
    for idx, ch := range s {
        fmt.Printf("字节偏移:%d 字符:%c\n", idx, ch)
    }

    // 3. 按“字”截取前 3 个字符：先转为 []rune 再左闭右开截取 [0:3]
    chars := []rune(s)
    fmt.Println(string(chars[0:3])) // 输出: Go语
}
string_ops.go · 拼接、strings 工具包与 strconv 数字互转 [Go 1.22+] 
package main

import (
    "fmt"
    "strconv"
    "strings"
)

func main() {
    // 1. 少量拼接用 + 或 fmt.Sprintf；循环内高频拼接用 strings.Builder
    info := fmt.Sprintf("user=%s, id=%d", "alice", 42)
    var b strings.Builder
    b.WriteString("select * ")
    b.WriteString("from orders")

    // 2. strings 常用方法 + strconv 字符串与数字转换
    parts := strings.Split(strings.TrimSpace(" a,b,c "), ",")
    joined := strings.Join(parts, "-") // "a-b-c"
    num, err := strconv.Atoi("2026")    // string -> int (int -> string 用 strconv.Itoa)
    fmt.Println(info, b.String(), joined, num, err)
}

02.4 · 流程控制：支持前置语句的 if、统一循环 for 与自动跳出的 switch

02.4 流程控制语法：if、for 与 switch

相比 JavaScript，Go 的控制流做了三处减法：条件外不写圆括号 ()（但左花括号 { 必须同行）、没有 while 也没有三元运算符 a ? b : c，所有循环统一用 for、switch 每个分支执行完默认自动跳出（不用写 break）：

if_and_switch.go · if 前置短语句与 switch 多值分支 [Go 1.22+] 
package main

import "fmt"

func main() {
    // 1. if 支持前置初始化语句（变量 n 作用域被限制在当前 if/else 块内，不污染外部）
    if n := len("hello"); n > 3 {
        fmt.Println("长度大于 3:", n)
    }

    // 2. switch 默认不穿透，且支持无表达式写法（替代冗长的 if-else if 链）
    day := "Sat"
    switch day {
    case "Sat", "Sun":
        fmt.Println("周末休息")
    default:
        fmt.Println("工作日")
    }
}
for_loops.go · for 替代传统三段式、while 与无限循环 [Go 1.22+] 
package main

import "fmt"

func main() {
    // 写法①：经典三段式（Go 1.22+ 也支持简写为 for i := range 3）
    for i := range 3 {
        fmt.Print(i, " ") // 0 1 2
    }

    // 写法②：只写条件 —— 等价于 JS 的 while (count < 2)
    count := 0
    for count < 2 {
        count++
    }

    // 写法③：for {} 无限循环 —— 常用于后台轮询消费者，配合 break / return 退出
    for {
        if count >= 2 {
            break
        }
    }
}

本章即时场景题（先想答案，再点击展开）

1. 产品需求要求「用户昵称最多 8 个字」，前端传了 4 个汉字 "草莓奶昔"，后端写 if len(nickname) > 8 为什么误判拦截了？

因为 Go 的 string 按 UTF-8 存储，每个常用汉字占 3 字节，4 个汉字的 len(nickname) 是 12 字节，直接触发了大于 8 的拦截。校验字符数应改为 if utf8.RuneCountInString(nickname) > 8；如果还要把超长昵称截断保留前 8 个字，则先转 r := []rune(nickname) 再取 string(r[:8])，切忌直接写 nickname[:8]（会在第 8 字节处劈开第 3 个汉字产生乱码）。

2. 写优惠券核销代码时用 float64 计算金额：0.1 + 0.2 == 0.3 为真吗？后端存金额的标准做法是什么？

不为真（与 JS 一样遵循二进制浮点标准，算出来是 0.30000000000000004）。生产环境处理金额有两种标准方案：① 统一放大为最小货币单位“分”并用 int64 整数存储计算（例如 19.90 元 存为 1990 分，最简单且无精度损失）；② 涉及多币种汇率或多位小数计息时，数据库用 DECIMAL，Go 代码使用定点数库 github.com/shopspring/decimal。

3. 想把数字 65 转成字符串 "65"，写习惯了强制类型转换随手敲了 string(65)，会得到什么？

会得到字母 "A"（且新版 go vet 会直接报警提示），因为将整数直接强转为 string 在 Go 语义里表示“把该整数当作 Unicode 码点转成对应字符”（65 正好是大写字母 A 的 ASCII 码）。把整数转十进制数字文本必须使用 strconv.Itoa(65) 或 strconv.FormatInt(id, 10)。
