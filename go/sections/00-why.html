🧭 00.1 · 语言定位：Go 语言的设计特点与常见应用领域

🧭 00.1 Go 语言的设计特点与常见应用领域

Go（又称 Golang）由 Google 于 2009 年开源，由 Ken Thompson（Unix 与 UTF-8 共同设计者）、Rob Pike 与 Robert Griesemer 主持设计。它的核心目标是把静态编译语言的运行效率，与动态脚本语言的开发简洁性结合起来：

① 语法极简，团队代码风格统一
整门语言只有 25 个保留关键字，仅有一种循环写法（for），并自带官方格式化工具 gofmt，不同工程师写出的代码长相几乎一致，阅读他人代码非常轻松。
② 原生支持高并发（goroutine）
在任意函数前加一个 go 关键字就能启动一个轻量级协程，初始仅占 2KB 内存，单机可轻松并发处理数万个网络连接。
③ 编译极快，单二进制文件直接部署
几万行代码通常只需几秒即可编译完成；编译产物是一个包含了运行时（Runtime）的独立可执行文件，拷到服务器上无需安装虚拟机或依赖库即可直接运行。

💼 在实际开发中，我们通常用 Go 来写什么？
1. 互联网后端微服务与 API 网关（高并发 HTTP / gRPC 接口服务）；
2. 云原生基础设施与容器工具（Docker、Kubernetes、etcd、Prometheus、Terraform 等全部由 Go 编写）；
3. 高性能中间件、消息推送、爬虫与跨平台命令行工具（CLI）。

🛠️ 00.2 · 环境搭建：Go 编译器安装、GOPROXY 国内镜像配置与开发工具准备

🛠️ 00.2 开发环境安装、国内镜像配置与编辑器准备

在动手写代码前，需要先在本地安装 Go 官方工具链（包含编译器、标准库与包管理工具），并配置好国内下载镜像。

💻 Step 1 · 三大操作系统安装 Go 工具链 
# 【macOS】推荐使用 Homebrew 一键安装（或从官网下载 .pkg 安装包）
$ brew install go

# 【Windows】使用 Winget 安装（或从 go.dev/dl 下载 .msi 安装包双击安装）
# 安装程序会自动将 C:\Program Files\Go\bin 添加到系统 PATH 环境变量
$ winget install GoLang.Go

# 【Linux】解压官方压缩包至 /usr/local/go 并配置 PATH
$ sudo rm -rf /usr/local/go && sudo tar -C /usr/local -xzf go1.24.0.linux-amd64.tar.gz
$ export PATH=$PATH:/usr/local/go/bin
⚡ Step 2 · 验证安装并配置国内模块代理（必配） 
# 1. 验证安装是否成功
$ go version
go version go1.24.0 darwin/arm64

# 2. 开启 Go Modules 并配置国内加速镜像（防止下载第三方库和插件超时）
$ go env -w GO111MODULE=on
$ go env -w GOPROXY=https://goproxy.cn,direct

# 3. 查看当前生效的核心环境配置
$ go env GOROOT GOPATH GOPROXY
核心环境变量 作用说明 初学者常见疑问与实践建议
GOROOT Go 编译器与官方标准库（如 fmt、net/http）的安装路径 安装好后自动识别，无需手动修改。
GOPATH 第三方依赖包缓存（$GOPATH/pkg/mod）与命令行工具（$GOPATH/bin）的存放目录 默认在用户目录的 ~/go 下。注意：现代 Go 采用 go.mod 管理项目，你自己的项目代码可以新建在电脑任意文件夹下（如桌面），完全不需要放进 GOPATH 里。
GOPROXY 拉取第三方依赖包时的镜像代理地址 默认的 proxy.golang.org 在国内无法直连，首次装好后执行 go env -w GOPROXY=https://goproxy.cn,direct 即可永久生效。
🧰 代码编辑器（IDE）选择建议：
• VS Code（免费轻量）：在扩展商店搜索安装官方 Go 插件（由 Go Team at Google 发布）。装好后按 Cmd+Shift+P（Windows 按 Ctrl+Shift+P），输入并执行 Go: Install/Update Tools，全选安装代码补全工具 gopls（上面配好 GOPROXY 后几秒即可装完）。
• JetBrains GoLand（功能完备）：安装后开箱即用，直接点击 New Project → Go 即可开始编写代码。
🚀 00.3 · 第一个程序：main.go 的组成部分与编译运行命令

🚀 00.3 第一个 Go 程序：main.go 的结构与运行方式

每个可独立运行的 Go 程序，都从 main 包（package main）里的 main() 函数开始执行。下面是最基础的源码结构与常用运行命令：

🐹 main.go · 最小可运行程序拆解 
// 1. 声明所属包名：只有名为 main 的包才能编译成可执行程序
package main

// 2. 导入标准库格式化输出包 fmt
import "fmt"

// 3. 程序唯一入口函数：无参数、无返回值
func main() {
    fmt.Println("Hello, Go!")
    // 输出: Hello, Go!
}
💻 Terminal · 编译与运行命令 
# 方式一：开发调试时直接编译并运行（不在当前目录留下二进制文件）
$ go run main.go
Hello, Go!

# 方式二：编译生成独立可执行文件（适合部署上线）
$ go build -o app main.go
$ ./app
Hello, Go!
📋 00.4 · 语法全景：25 个保留关键字分类表与预声明内置标识符

📋 00.4 语法全景：25 个保留关键字与预声明内置标识符

在开始学习具体的数据类型之前，可以先对 Go 的全部关键字有一个整体印象。Go 语言一共只有 25 个保留关键字，按用途正好分为四类：

分类（共 25 个） 保留关键字清单 对应的语法设计说明
1. 包与声明（6 个） package、import、var、const、type、func • 可见性规则：没有 public / private 关键字，直接通过标识符首字母大小写控制可见性（首字母大写如 Println 可被外部包调用，首字母小写仅在当前包内可见）。
• 常量枚举：没有 enum，通过 const 配合 iota 定义枚举。
2. 复合类型（4 个） struct、interface、map、chan • struct 定义结构体；interface 定义行为接口；map 定义键值字典；chan 定义协程间通信通道。
3. 流程控制（12 个） if、else、switch、case、default、for、range、break、continue、goto、fallthrough、return • 循环只有 for：没有 while / do，所有循环统一用 for。
• 分支默认不穿透：switch 的每个 case 执行完自动结束，不用手写 break。
• 错误处理：没有 try / catch，函数直接将 error 作为返回值返回。
4. 并发与延迟（3 个） go、select、defer • go 启动并发协程；select 同时监听多个通道；defer 在函数退出前执行资源清理。
💡 除了 25 个保留关键字，Go 还预先提供了三类「预声明标识符（builtin）」：
平时写代码经常用到的 int、string、true、nil、make、len 等并不在上面 25 个关键字里，它们是语言内置提供好的标识符：
1. 内置基础类型名：bool、byte、rune、int / int8..int64、uint / uint8..uint64、float32 / float64、string、error、any；
2. 内置常量值与计数器：true、false、nil（空值）、iota（常量行计数器）；
3. 内置操作函数：make、new、len、cap、append、copy、delete、close、clear、panic、recover。
