📝 01.1 变量声明、默认零值与常量枚举（const / iota）

① 变量的四种声明方式与“零值”设计：在 Go 中声明变量有四种常见写法。与其他静态语言不同，Go 保证任何声明后未显式赋初值的变量，都会自动赋予该类型的“零值（Zero Value）”，绝不会出现未初始化的随机内存数据：

🐹 vars.go · 四种变量声明写法与零值 
package main
import "fmt"

// 函数外部（包级变量）必须使用 var 关键字声明
var appVersion = "1.0.0"

func main() {
    var a int = 10   // 1. 完整声明：显式写出类型与初始值
    var b = 20       // 2. 类型推导：省略类型，编译器自动推导为 int
    c := 30          // 3. 短变量声明（函数内最常用）：声明并直接赋值

    // 4. 零值声明：只声明不赋值，自动获得该类型的安全零值
    var count int    // 数值型零值: 0
    var title string // 字符串零值: "" (空字符串)
    var ready bool   // 布尔型零值: false

    fmt.Println(a, b, c, count, title == "", ready)
    // 输出: 10 20 30 0 true false
}
🐹 const_iota.go · 常量与 iota 自动递增枚举 
// 单个常量声明（编译期确定，运行期不可修改）
const MaxRetries = 3

// 使用 const (...) 块配合 iota 定义连续枚举值：
// 每个 const 块内，iota 从第 0 行起初始为 0，每往下一行自动 +1
const (
    StatusPending = iota // 第 0 行: iota = 0
    StatusRunning        // 第 1 行: 沿用上一行表达式，iota = 1
    StatusSuccess        // 第 2 行: iota = 2
    StatusFailed         // 第 3 行: iota = 3
)

// 也可配合位运算 1 << iota 定义权限位掩码（1, 2, 4...）：
const (
    PermRead  = 1 << iota // 1 << 0 = 1 (二进制 001)
    PermWrite             // 1 << 1 = 2 (二进制 010)
    PermExec              // 1 << 2 = 4 (二进制 100)
)

💡 数值运算与显式类型转换规则：为了防止不同精度的数字在混合运算时悄悄丢失精度，Go 没有任何隐式类型转换——哪怕是 int 和 int64 相加，也必须使用 目标类型(变量) 显式转换后再运算：

🐹 number_convert.go · 显式类型转换用法示例 
var count int = 10
var total int64 = 1000

// 不同数值类型之间运算，使用 T(v) 显式转换：
sum := int64(count) + total          // 将 int 显式转为 int64 后相加，结果: 1010

// 整数相除求小数比例时，先转为 float64 再除（否则整数 3 / 10 结果为 0）：
rate := float64(3) / float64(count)  // 结果: 0.3
🔤 01.3 · 字符与字符串：byte / rune / string 关系与日常字符串操作大全

🔤 01.3 字符与字符串：byte / rune / string 的日常用法

① 先分清 byte、rune 与 string：
在 Go 中，字符串默认采用 UTF-8 编码存储——英文字符和数字每个占 1 个字节，而中文字符通常每个占 3 个字节。因此 Go 提供了两种字符类型来配合 string 使用：

  • byte（uint8，1 字节）：用来处理纯英文 ASCII 字符或二进制字节流（如读写文件、JSON 字节数组 []byte）；
  • rune（int32，4 字节）：用来表示一个完整的字符（Unicode 码点）。当字符串里包含中文或多国文字，需要按“第几个字”来统计字数、遍历或截取时，就用 rune；
  • string 字面量：用双引号 "Hello\n" 定义普通字符串（支持转义符），用反引号 `多行原样文本` 定义跨行字符串（常用于写 SQL 语句、正则表达式或 JSON 模板）。
🐹 string_len_sub.go · 求长度、遍历与含中文截取 
import (
    "fmt"
    "unicode/utf8"
)

func main() {
    s := "Go语言" // 'G'(1B) + 'o'(1B) + '语'(3B) + '言'(3B)

    // 1. len(s) 返回的是底层字节数；统计实际字符个数用 RuneCountInString：
    fmt.Println(len(s))                    // 输出: 8 (字节数)
    fmt.Println(utf8.RuneCountInString(s)) // 输出: 4 (字符个数)

    // 2. 使用 for range 遍历字符串，每次自动按完整字符 (rune) 解码：
    for idx, ch := range s {
        fmt.Printf("字节位置:%d 字符:%c\n", idx, ch)
    }

    // 3. 按字符个数截取前 3 个字：先转为 []rune 切片再截取
    chars := []rune(s)
    fmt.Println(string(chars[0:3]))        // 输出: Go语
}
🐹 string_ops.go · 日常最常用的拼接、查找切分与数字互转 
import (
    "fmt"
    "strconv"
    "strings"
)

// 1. 字符串拼接：少量用 + 或 fmt.Sprintf；循环拼接用 strings.Builder
msg := "Hello, " + "Alice"
info := fmt.Sprintf("user=%s, id=%d", "alice", 42)

// 2. strings 标准库常用操作（判断包含、切分、连接、去首尾空格）：
hasGo := strings.Contains("golang", "go")       // true
parts := strings.Split("a,b,c", ",")            // ["a", "b", "c"]
joined := strings.Join(parts, "-")              // "a-b-c"
clean := strings.TrimSpace("  hello \n")       // "hello"

// 3. strconv 包：字符串与数字互相转换
numStr := strconv.Itoa(2026)                     // int -> string: "2026"
num, err := strconv.Atoi("2026")                 // string -> int: 2026
_, _, _, _, _ = msg, info, hasGo, joined, clean
_, _ = numStr, num; _ = err
🔀 01.4 · 流程控制：支持前置语句的 if、统一循环 for 与自动跳出的 switch

🔀 01.4 流程控制语法：if、for 与 switch

Go 的控制流语法在 C 语言基础上做了三处简化：条件表达式外不需要写圆括号 ()、循环只有 for 一种关键字、switch 分支默认自动跳出不穿透：

🐹 if_and_switch.go · if 前置语句与 switch 用法 
// 1. if 支持在条件前写一句简短初始化语句（变量 n 作用域仅限 if/else 块内）
if n := len("hello"); n > 3 {
    fmt.Println("长度大于 3, 当前为:", n)
} else {
    fmt.Println("长度不超过 3")
}

// 2. switch：每个 case 执行完自动结束（无需写 break），且一个 case 可匹配多个值
day := "Sat"
switch day {
case "Sat", "Sun":
    fmt.Println("周末休息")
default:
    fmt.Println("工作日")
}
🐹 for_loops.go · for 循环的三种日常写法 
// 写法①：经典三段式循环（初值; 条件; 步进）
for i := 0; i < 3; i++ {
    fmt.Println("i =", i)
}

// 写法②：只写条件（相当于其他语言的 while 循环）
count := 0
for count < 2 {
    count++
}

// 写法③：for {} 无限循环（常用于后台服务主循环，配合 break 跳出）
for {
    if count >= 2 {
        break
    }
}
