面向熟悉 JavaScript 但没写过 Go 的开发者与日常快速复习：从系统选型边界、给 JS 开发者的四项思维切换与五分钟跑通首个程序出发，依次掌握基础类型、切片与字典共享陷阱、结构体接口泛型与前后端 JSON 避坑、分层业务错误处理，再深入协程并发实战模式、数据库与缓存接入、鉴权超时中间件、流式推送与消息消费八大通用后端场景，最后配齐标准工程目录、结构化日志、优雅停机、自动化测试、容器构建、线上排障与十道综合场景自测。若需深挖运行时底层实现，可从各节末尾链接随时切换至 核心原理篇 ↗。

00 · 全景科普：Go 语言定位、Node/Java 对比与 JS 思维切换

厘清后端与云原生偏爱 Go 的原因及适用边界，对比 Node.js 与 Java，梳理写给 JS 开发者的四项思维切换与全篇知识地图。

01 · 跑起来：环境安装、GOPROXY、编辑器与第一个程序

五分钟完成全平台安装与国内代理镜像配置，配齐 VS Code / GoLand 工具链，跑通 go run 与 go build。

02 · 基础类型与控制流：变量零值、数值转换、字符串与分支循环

掌握短变量声明、默认零值、iota 枚举、显式数值转换、含中文 rune 字符串截取拼接以及 if / for / switch 语法。

03 · 切片与字典：日常增删改查、共享底层数组陷阱与并发崩溃防护

熟练操作动态切片与哈希字典，重点避开子切片改一个变两个、append 覆盖原数组以及 map 并发写直接终止进程等常见误区。

04 · 结构体、接口与泛型：指针组合、JSON 四大常见坑与类型约束

掌握指针与方法接收者选择，解决 nil 切片转 null、omitempty 吞零值、时间格式与 64 位大整数丢精度，用好非侵入式接口与泛型。

05 · 函数与错误处理：defer 资源释放、业务错误分层与 panic 边界

图解 defer 后进先出栈与返回时机，落地数据层至接口层统一映射 HTTP 状态码的错误处理闭环，明确 panic 与 recover 边界。

06 · 并发实战：协程通道、锁与 Context、三大并发模式与防泄漏

掌握协程、通道、读写锁与 Context 配合，落地 Worker Pool、errgroup 与带超时扇出扇入，排查协程泄漏与 -race 数据竞争。

07 · 常见业务场景实战：MySQL、Redis、中间件、HTTP调用、SSE、MQ 与 CLI

按需求落地数据库连接池与事务、go-redis、JWT 鉴权与超时中间件、重试 HTTPClient、SSE 流式断连即停、MQ 消费、CLI 与 Gin 选型。

08 · 项目搭建与上线：目录分层、slog 日志、优雅停机、测试、Docker 与 pprof

配齐 cmd/internal/pkg 目录、环境变量配置、log/slog、双健康探针与平滑停机、表格测试与 httptest、多阶段小镜像构建及 pprof 速查。

09 · 场景自测与附录：10 道实战排障题与 25 个保留关键字速查表

通过默认折叠的 10 道真实开发与线上故障题检验全篇掌握度，文末附 25 个保留关键字与内置标识符速查附录。
