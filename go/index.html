00 · 认识 Go、环境安装与第一个程序：工具链配置、Hello World 与 25 个保留关键字

了解 Go 的应用场景，完成编译器安装与国内 `GOPROXY` 镜像配置，运行第一个程序并一览 25 个保留关键字。

01 · 变量、常量与基础数据类型：bool / int / float / string / byte / rune 与控制流

系统梳理变量声明、零值机制、常量与 `iota`、基本数值与字符串日常操作，以及 `if / for / switch` 控制流语法。

02 · 复合数据类型：数组 [N]T、动态切片 []T 与键值字典 map[K]V 的日常用法

掌握切片的创建、追加、截取、拷贝，以及字典的增删改查、存在性判断与容量预留技巧。

03 · 指针、结构体（struct）与接口（interface）：Go 的组合式面向对象

理解值传递与指针、结构体的定义与嵌套、方法接收者的选择、JSON 结构体标签，以及接口多态与泛型。

04 · 函数特性、defer 资源清理与显式错误处理（error）

掌握多返回值函数、闭包、用 `defer` 关闭文件与释放锁，以及 `error` 包装与判断的标准写法。

05 · 并发编程入门：启动协程 go、通道 channel 通信与同步工具（WaitGroup / Mutex / Context）

学会在实际代码中开启协程、用通道传递任务与结果、用 `WaitGroup` 等待完成、用锁保护共享变量，以及用 `Context` 控制超时。

06 · 实际开发中 Go 项目怎么搭建与实战：go mod、标准目录结构与 HTTP 服务

从 `go mod init` 开始，详解真实项目的 `cmd / internal / pkg` 分层目录结构、包导入规则，并手写一个完整的 HTTP JSON 服务与单元测试。
