本地启动与调试

准备 Git、Node.js ≥ 22.19 和模型凭据。VS Code 打开「JavaScript Debug Terminal」，在该终端执行：

git clone https://github.com/earendil-works/pi.git
cd pi
git checkout 62752fd4c37a
npm ci --ignore-scripts
./pi-test.sh

脚本直接运行 TypeScript 源码；需要登录时输入 /login。文件操作请在临时项目中做。
