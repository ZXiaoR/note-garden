最小循环解决“动作怎样执行”。为了让真实任务持续推进，还要按需求补上输入调度、历史保存、上下文管理、工具发现、执行校验、副作用协调与暂停恢复。围绕模型与工具循环组织这些运行机制，就是本页讨论的 Harness。

遇到具体问题

任务中途补充了要求，或者上下文里积累了大量工具输出。先描述触发条件和影响。

增加对应机制

用队列与检查点接收输入，用预算、摘要或文件外置管理上下文。按场景选择需要的能力。

读源码验证实现

队列在哪里消费？摘要何时触发？结果怎样写回？异常时如何处理？把设计名词落实到数据、状态与执行路径。

所以下面比较开源方案，是为了学习不同的落地方式：机制如何组合，哪些默认提供，哪些交给扩展，以及各自付出了什么复杂度。简单循环本身也是 Harness 的起点；工程能力应随任务需要增加。

最小参照：mini-swe-agent

它以 Bash 驱动、线性历史和独立执行的 Shell 动作展示一个简洁实现。可以先用它观察“模型提出动作，宿主执行后把结果送回”的闭环。查看官方实现 ↗

选读 · 六个开源方案：这些工程问题分别怎样落地？

带着图 2 的问题看 Pi、Deep Agents、DSH、OpenCode、Codex 与 OpenHands SDK：它们优先完善哪些机制，用什么结构组合能力？下面先比较设计侧重点，读源码时再追踪具体实现。

Pi

精简核心 + 扩展边界

侧重点
关注一次 Coding Agent 会话怎样清晰地运转。
亮点
循环、会话与工具链可沿源码追踪；通过扩展、Skills 和 SDK 适配工作方式。
阅读取舍
适合先学习基础机制；复杂协作流程通常需要自行组合扩展。
Pi README（导读版本） ↗

Deep Agents

长任务能力的默认组合

侧重点
关注多步任务中的计划、上下文与子任务委派。
亮点
将规划、文件后端、摘要、长输出卸载和独立上下文的子 Agent 组合起来。
阅读取舍
默认能力丰富；读源码时需要同时理解 LangChain 中间件与 LangGraph 运行时。
Deep Agents README ↗

DeepSeek Harness

可组合的插件运行底座

开发者预览 · 本页核对：2026-11-08

侧重点
关注运行能力怎样被装配、替换和扩展。
亮点
以 Cordis 插件树组织模型、工具、日志和循环，Profile / Bundle 描述能力组合。
阅读取舍
适合学习可组合架构；阅读时需要先理解插件生命周期和事件接口。
DSH 架构文档 ↗

OpenCode

产品化的 Coding Agent 体验

侧重点
关注开发者在探索、计划和执行之间如何切换。
亮点
Build / Plan 内置 Agent、general 子 Agent，以及终端、桌面和 Web 界面；可对照研究模式与能力边界。
阅读取舍
适合在理解循环后看完整交互产品；UI、会话与 Agent 能力需要分层阅读。
OpenCode 官方仓库 ↗

Codex Harness

运行边界 + 应用集成

侧重点
关注会话状态、执行事件与应用如何控制 Agent。
亮点
组织跨回合状态、流式执行和配置的沙箱 / 审批策略；app-server 提供会话、事件与审批接口。
阅读取舍
适合研究产品集成与宿主边界；CLI、app-server、SDK 和模型服务需要区分。
OpenAI 官方架构说明 ↗

OpenHands SDK

执行环境 + 服务化边界

侧重点
关注代码 Agent 怎样在不同工作空间中运行并接入应用。
亮点
以 Agent、Tool、Conversation、Workspace 等对象组织能力；Agent Server 支持本地或临时容器工作空间。
阅读取舍
适合研究执行环境与部署；SDK / Agent Server、界面和自动化调度分别属于不同组件。

带着图 2 的问题读源码，为什么以 Pi 为主线？

图 2 按场景列出了工程问题与处理步骤；接下来读源码，是要找到它们的实现位置、触发条件和状态变化。可以先用 mini-swe-agent 理解最小循环，再沿 Pi 的一条修 Bug 路径，追踪输入怎样调度、上下文怎样管理、工具怎样校验和执行。然后带着同样的问题对照其他方案。

1 · 从可追踪的闭环开始

输入 → 组装请求 → 模型响应 → 工具执行 → 结果回填。沿同一个场景认识宿主与模型的分工。

2 · 看清核心与策略的边界

区分默认循环、参数校验与钩子槽位，也区分可选路由和审批扩展。学习一种能力应放在哪一层。

3 · 带着问题读其他实现

再看 Deep Agents 的能力组合、DSH 的插件树、OpenCode 的产品组织、Codex 的应用接口与 OpenHands 的执行环境，最后进入 SuperAgent 的工单应用。
