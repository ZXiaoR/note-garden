Redis · 基础与实战篇：环境配置、数据类型选型、缓存工程与分布式协调

面向日常后端开发与线上运维实操：从 Redis 与关系型数据库的分层定位、全平台安装配置、ACL 账号授权与客户端连接池起步，依次梳理键空间管理规范与批量管道优化、五种基础类型与四种高阶扩展类型的业务选型、旁路缓存模式与三大缓存异常代码防护、混合持久化与内存水位规划，最后落地主从哨兵集群部署、生产级分布式锁与 Stream 消息队列。

00 · 架构定位、全平台环境部署与第一个 Redis 程序

阐明 Redis 内存状态层与关系型数据库的协同分工，提供 Docker Compose 与本地安装模板、核心配置表、ACL 最小权限建号以及 go-redis/v9 连接池示例。

01 · 键空间管理、通用指令、Pipeline 批处理与慢查询排查

梳理企业级分段 Key 命名约定、TTL 特殊返回值与异步删除 UNLINK，详解 SCAN 游标循环规则、Pipeline 合并网络 RTT 实战与 SLOWLOG 诊断方法。

02 · 五大基础数据类型与四大扩展类型实战指南

逐一演练 String / Hash / List / Set / ZSet 的高频命令与业务代码（含购物车、抽奖去重与实时排行榜），并涵盖 Bitmap 签到、HyperLogLog UV 统计与 GEO 检索。

03 · 缓存读写模式、三大异常防护与大 Key / 热 Key 治理

图解 Cache-Aside 标准读写闭环，整合空值占位、singleflight 请求归并与随机抖动 TTL 代码防御穿透/击穿/雪崩，并给出大 Key 分桶拆分与热 Key 二级缓存治理方案。

04 · 持久化配置方案、灾难备份恢复与内存淘汰策略选型

对比 RDB、AOF 与混合持久化生产配置及 Redis 7.0 Multi-Part AOF 文件结构，图解服务器物理内存 70% 安全水位规划与 8 种 maxmemory 淘汰策略选型矩阵。

05 · 高可用与分布式部署：主从复制、Sentinel 哨兵与 Cluster 分片集群

图解主从、哨兵与 Cluster 三种生产拓扑的容量边界，提供 replicaof、3 节点 Sentinel 防脑裂配置、3 主 3 从集群创建及 {Hash Tag} 同槽多键实操。

06 · 分布式协调与实战扩展：分布式锁、Lua 脚本、Stream 消费组与自测

封装带唯一令牌、Lua 原子解锁与看门狗自动续期的 Go 分布式锁，辨析 MULTI 事务与 Lua 脚本，演练 Stream 消费者组 PEL / XACK / XAUTOCLAIM 闭环与 8 道实战自测。
