01 · 性能与线程模型：Redis 为什么这么快？单线程 Reactor、epoll 多路复用与 Redis 6.0+ 多线程 I/O

02 · 数据类型与底层结构：5 种基础 + 4 种扩展类型、redisObject、SDS、跳表 skiplist、listpack 与渐进式 rehash

03 · 缓存实战避坑：穿透 / 击穿 / 雪崩防御、布隆过滤器、MySQL × Redis 双写一致性与 BigKey / HotKey 治理

05 · 高可用三级演进：主从复制（replid + offset 增量/全量）→ 哨兵 Sentinel（SDOWN/ODOWN 与 Raft 选主）→ Cluster 16384 哈希槽
