00 · 第一性原理导读：我们为什么学 MySQL？入门懂什么就够、进阶到底在解决什么？

从直接读写裸磁盘文件的三大工程死穴（全表扫描慢、并发读写脏数据、断电半写丢数据）出发，推导 MySQL InnoDB「存储与 B+ 树索引、MVCC 与行锁并发控制、三大日志与主从高可用」三大进阶主线。

01 · 起步：从一张 users 表开始，看一条 SQL 在 Server 层与 InnoDB 引擎层的完整旅程

建立贯穿全文的 users 实验表，拆解连接器、解析器、优化器、执行器与 InnoDB 存储引擎层的两层分工协作。

02 · 存储与内存：为什么需要 16 KiB 数据页、B+ 树多级页目录与 Buffer Pool 缓冲池？

详解 InnoDB 16 KiB 页结构、3 层 B+ 树如何支撑千万级数据仅需 3 次 I/O、为什么选 B+ 树而非 B 树/哈希/跳表，以及 Buffer Pool 冷热双段 LRU 与脏页管理。

03 · 查询加速：聚簇索引 vs 二级索引、回表与覆盖索引、最左前缀原则、索引下推 ICP 与 EXPLAIN 验证

对比聚簇索引与二级索引叶子节点差异，拆解联合索引排序规则、范围查询后的列、Index Condition Pushdown (ICP)、常见索引失效根因，以及 EXPLAIN 核心字段（type / key / key_len / Extra）判读。

04 · 并发正确：事务 ACID、四大隔离级别、脏读/不可重复读/幻读与 MVCC ReadView 版本链推演

厘清四大隔离级别标准，深入 InnoDB 隐藏列（DB_TRX_ID / DB_ROLL_PTR）、Undo Log 版本链与 ReadView 四大水位字段，手把手推演 RC 与 RR 下的可见性判断与快照读/当前读防幻读机制。

05 · 并发互斥：全局锁/表锁/意向锁、Record Lock / Gap Lock / Next-Key Lock 加锁退化规则与死锁排查

通过数轴图解记录锁、间隙锁与临键锁，结合唯一索引等值/范围查询与非唯一索引场景推演 InnoDB 自动加锁范围，提供生产级行锁等待与死锁日志排查 SQL。

06 · 可靠与高可用：Undo Log / Redo Log / Binlog 三大日志、两阶段提交 (2PC)、双 1 配置与主从复制

详解 WAL 预写日志、Redo Log 与 Binlog 两阶段提交防不一致、Doublewrite Buffer 防部分写失效、三档刷盘配置（双 1 / 折中 / 高吞吐）、异步/半同步/MGR 主从复制与缓存双写一致性。

07 · 串联与实验：SELECT 与 UPDATE 全链路复盘 + 双会话亲手验证 MVCC 快照与行锁等待

将前 6 章机制串联为完整的读写执行流，并配套可直接复制执行的双终端会话 SQL 实验。
