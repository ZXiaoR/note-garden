00 · 认识浏览器与第一个网页：HTML、CSS、JavaScript 与开发者工具入门

理解浏览器的核心职责与网页三要素分工，手写第一个可交互网页，并掌握 Chrome DevTools 六大面板的日常用途。

01 · 网址解析与网络请求基础：URL 组成、HTTP 报文与 Fetch API 日常调用

拆解标准 URL 的六个组成部分，认识 HTTP 请求响应报文与常见状态码，并用原生 fetch 发起带超时控制的异步请求。

02 · DOM 节点操作与事件交互：元素查询、动态渲染、事件流与事件委托

掌握 DOM 树增删改查标准 API、事件传播三阶段（捕获、目标、冒泡），以及利用事件冒泡实现高效的事件委托。

03 · 页面布局与脚本加载属性：CSS 盒模型、布局方式与 script / defer / async

区分标准盒模型与 border-box、三种元素隐藏方式，以及普通 script、defer、async、module 与页面生命周期事件的关系。

04 · 异步任务、定时器与动画更新：定时器、Promise、requestAnimationFrame 与 Web Worker

理解主线程异步回调顺序，使用 requestAnimationFrame 实现流畅动画，并用 Web Worker 线程拆分耗时计算。

05 · 本地存储与跨域接口联调：Cookie、Web Storage、缓存配置与 CORS 排障

对比四大浏览器本地存储方案，掌握生产环境静态资源缓存配置策略，并解决前后端分离开发中的 CORS 跨域报错。

06 · 实战演练与日常排障：端到端交互应用搭建、Network 抓包与 Performance 诊断

手写带本地持久化的完整待办清单应用，并梳理使用 Network 与 Performance 面板定位页面加载慢与卡顿的标准步骤。
