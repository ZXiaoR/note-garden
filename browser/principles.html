01 · 页面导航与网络协议演进：DNS、TCP/TLS 握手、HTTP/2 → HTTP/3 与导航提交

02 · HTTP 缓存状态机与离线存储：强缓存新鲜度、ETag 协商验证与 Service Worker

04 · Blink 渲染流水线与合成器架构：Layout 树、合成层、光栅化与重排重绘

拆解 Style → Layout → Layer → Paint → Tiling/Raster → Composite 六阶段管线，辨析重排、重绘、硬件加速合成、强制同步布局与层爆炸。

05 · HTML 事件循环规范与一帧生命周期：任务队列、微任务检查点、rAF 与 rIC

还原 WHATWG 多优先级任务队列与微任务检查点，图解 16.7ms VSync 一帧内宏任务、微任务、rAF、渲染与 rIC 的精确执行顺序。
