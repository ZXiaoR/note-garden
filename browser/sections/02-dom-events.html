02.1 · 文档对象模型：从 HTML 标签到 DOM 节点树的映射与日常操作 API

02.1 从 HTML 标签到 DOM 节点树与常用操作 API

HTML 本质上是一段纯文本字符串，JavaScript 无法直接修改纯文本里的某个按钮。因此，浏览器在读取 HTML 时，会把每一个标签、每一段文字转换为内存里的 JavaScript 对象，并按照父子嵌套关系连接成一棵树——这就是文档对象模型（Document Object Model，简称 DOM）。

操作分类 推荐使用的标准 DOM API 作用说明与安全注意事项
① 查找元素 document.querySelector('.card')
document.querySelectorAll('.item')		 传入任意 CSS 选择器（如 #id、.class、ul > li）。前者返回匹配的第一个元素（未找到返回 null），后者返回包含所有匹配元素的静态集合 NodeList。
② 读写文本与属性 el.textContent = '新标题'
el.dataset.userId = '108'		 优先使用 textContent 而非 innerHTML：textContent 会将字符串中的 <script> 当作普通文字显示，天然防止恶意脚本注入；dataset 对应标签上的 data-user-id="108" 自定义属性。
③ 切换样式类名 el.classList.add('active')
el.classList.remove / toggle('hidden')		 相比直接拼写 el.style.color = 'red'，在 CSS 中定义好 .active 样式再用 classList 切换类名，结构更清晰且易于维护。
④ 创建与批量挂载 document.createElement('li')
document.createDocumentFragment()		 需要循环插入上百个节点时，先将节点追加到内存中的轻量容器 DocumentFragment，循环结束后再一次性调用 parent.appendChild(fragment) 挂入页面，避免反复触发页面重新计算。

在事件处理函数中，有两个名称相似但职责完全不同的控制方法，切勿混用：

  • event.preventDefault()（阻止浏览器默认行为）：例如阻止点击 <a> 链接时的自动页面跳转，或阻止点击表单 <form> 提交按钮时的整页刷新，但它不会阻止事件继续向上冒泡。
  • event.stopPropagation()（停止事件继续传播）：让事件在当前元素停下，不再通知外层的父级监听器，但它不会阻止浏览器的默认行为。
02.3 · 工程最佳实践：利用事件冒泡实现「事件委托（Event Delegation）」

02.3 利用事件冒泡实现「事件委托」

假设页面上有一个包含 500 条商品的列表 <ul id="todo-list">，且后续还会通过脚本动态新增条目。如果用循环给 500 个删除按钮分别绑定 addEventListener，不仅会创建 500 个函数占用内存，而且后续动态插入的新按钮还没有绑定事件。
借助上面的事件冒泡机制，我们只需要在外层父容器 <ul> 上绑定1 个监听器，再通过 event.target 判断实际点击的是哪一个子按钮——这种模式称为事件委托（Event Delegation）：

event_delegation.js · 在父容器绑定单个监听器统一处理动态子元素点击 
const listEl = document.getElementById('todo-list');

// 只在父元素 <ul> 上注册 1 个点击监听器，哪怕后续动态 appendChild 的新 <li> 也能自动生效
listEl.addEventListener('click', (event) => {
  // event.target 是鼠标真正点中的最内层元素（可能是按钮里的图标 <span> 或 <button> 本身）
  // closest('.del-btn') 从点击点向上查找最近的 .del-btn 按钮（若点的不是删除按钮则返回 null）
  const delBtn = event.target.closest('.del-btn');
  if (!delBtn) return; // 点击的是列表空白处或其他区域，直接忽略

  // 找到该按钮所在的整行 <li class="todo-item" data-id="101"> 并将其从 DOM 树移除
  const itemEl = delBtn.closest('.todo-item');
  console.log('删除条目 ID：', itemEl.dataset.id);
  itemEl.remove();
});
