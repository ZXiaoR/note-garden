00.1 · 整体定位：浏览器的核心职责与 HTML、CSS、JavaScript 的协作关系

00.1 浏览器的核心职责与网页三要素分工

浏览器是连接用户与万维网（Web）的客户端程序。当我们在地址栏输入网址或点击链接时，浏览器负责通过网络向服务器请求资源，将收到的文本与字节流解析并绘制成屏幕上的可视化画面，同时持续响应用户的点击、输入与滚动操作。

一个标准的现代网页通常由三类代码协作构成，它们在浏览器内部各司其职：

第一要素 · 结构层 .html
HTML：定义网页的内容与骨架

超文本标记语言（HTML）通过成对的标签声明页面里有哪些元素，例如哪一段是标题（<h1>）、哪一段是正文（<p>）、哪里放一个按钮（<button>）。

第二要素 · 表现层 .css
CSS：定义元素的外观与排版

层叠样式表（CSS）通过选择器选中 HTML 元素，并规定它们的视觉属性，例如文字颜色、字号大小、边距留白以及多列并排方式。

第三要素 · 行为层 .js
JavaScript：定义交互与动态逻辑

JavaScript 是运行在浏览器中的脚本语言，负责监听用户操作（如点击按钮）、向后端接口请求数据，并实时修改页面上的文字或样式。

主流浏览器 渲染引擎（负责 HTML/CSS 与绘制） JS 引擎（负责执行脚本） 架构演进说明
Chrome / Edge / Arc Blink（源自 WebKit 分支） V8 基于开源项目 Chromium 构建，是目前桌面端与 Android 端市场占比最高的实现，本专题以此为主要参考。
Safari（macOS / iOS） WebKit JavaScriptCore (Nitro) Apple 主导维护，iOS 系统内置的 WebView 与桌面 Safari 均基于此内核。
Firefox Gecko SpiderMonkey Mozilla 独立研发的浏览器内核，严格遵循 W3C 与 WHATWG 标准规范。
00.2 · 第一个程序：手写包含 HTML、CSS 与 JavaScript 的最小可运行网页

00.2 编写并运行第一个完整网页

开发网页不需要预先安装复杂的编译工具。在电脑任意目录下新建一个名为 hello.html 的纯文本文件，写入下方代码后用浏览器直接打开，即可看到排版效果与点击交互。

hello.html · 最小可运行网页（保存后双击用浏览器打开） 
<!-- 1. 声明文档遵循现代 HTML5 标准模式 -->
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的第一个网页</title>
  <!-- 2. CSS 样式：选中 id 为 count-btn 的按钮设置外观 -->
  <style>
    #count-btn {
      padding: 8px 16px;
      color: #14226b;
      border: 2px solid #14226b;
      border-radius: 6px;
      cursor: pointer;
    }
  </style>
</head>
<body>
  <!-- 3. HTML 结构：一个段落与一个按钮 -->
  <p id="status-text">当前点击次数：0</p>
  <button id="count-btn">点我加 1</button>

  <!-- 4. JavaScript 脚本：监听按钮点击并更新段落文字 -->
  <script>
    let count = 0;
    const textEl = document.getElementById('status-text');
    const btnEl = document.getElementById('count-btn');

    btnEl.addEventListener('click', () => {
      count = count + 1;
      textEl.textContent = '当前点击次数：' + count;
    });
  </script>
</body>
</html>
逐行语法拆解（零基础对照）
  • <!DOCTYPE html>：位于文件第一行，告知浏览器按照现代标准模式解析页面，避免退化为早期兼容模式（怪异模式）。
  • <head> 与 <body>：<head> 存放编码声明（UTF-8）、网页标题与样式规则，不会直接显示在页面正文区；<body> 存放用户真正能看到的页面元素。
  • id="status-text" 与 #count-btn：id 属性给元素赋予页面内唯一的名称。在 CSS 中用井号 #count-btn 选中它设置样式；在 JavaScript 中用 document.getElementById('count-btn') 获取到这个元素对象。
  • let 与 const：let 声明后续需要修改数值的变量（如计数器 count）；const 声明一旦绑定后不再重新指向其他对象的常量引用（如获取到的元素 textEl）。
  • addEventListener('click', () => { ... })：为按钮注册一个点击事件监听器。每当用户点击按钮时，浏览器就会执行箭头函数 () => { ... } 花括号内的代码，将 count 加 1 并赋值给段落的 textContent（纯文本内容）属性。
00.3 · 调试工作台：Chrome 开发者工具（DevTools）六大核心面板的日常用途

00.3 浏览器开发者工具（DevTools）日常用法

在 Chrome 或 Edge 浏览器中打开任意网页，按下快捷键 F12（macOS 为 Cmd + Option + I，或在页面空白处右键选择“检查”），即可呼出内置的开发者工具（DevTools）。它是前端开发与网页排障最核心的观测窗口：

面板名称 主要观测对象 日常开发与排障中的典型操作
Elements（元素） 实时 DOM 树与生效的 CSS 样式 点击左上角箭头图标选中页面元素，查看其当前的 HTML 结构、盒模型尺寸（宽高、内边距、边框、外边距），并可直接在右侧 Styles 栏临时勾选或修改 CSS 属性实时预览效果。
Console（控制台） 脚本日志输出与交互式执行环境 查看代码中 console.log() 打印的调试信息与红色的未捕获异常报错；也可以直接在底部输入任意 JavaScript 表达式（如 document.title）回车立即查看返回值。
Sources（源代码） 页面加载的文件源码与断点调试 浏览当前网页加载的 HTML/CSS/JS 文件，在 JavaScript 代码行号上点击打上断点（Breakpoint）；当代码执行到该行时会自动暂停，方便逐行观察所有变量的当前数值。
Network（网络） 所有网络请求的发送、响应与耗时 观察网页加载或点击按钮时发出了哪些 HTTP 请求、状态码是 200 还是 404/500、请求头与响应 JSON 内容是什么，以及是否命中了本地缓存。
Application（应用） 浏览器本地存储与缓存数据 查看、编辑或清空当前网站保存在本地的 Local Storage、Session Storage、Cookies 与 IndexedDB 数据。
Performance（性能） 主线程任务耗时与每帧渲染流水线 录制几秒钟的页面加载或交互过程，通过火焰图定位哪段 JavaScript 函数执行过久、或者哪次样式修改引发了耗时较长的重排与重绘。
阅读指引：本篇（ 基础与实战篇）将顺着日常网页开发的认知顺序，把网络请求、DOM 与事件操作、CSS 布局与脚本加载、异步定时器、本地存储与跨域联调逐一讲透。如果你已经熟练掌握前端日常 API，希望直接深入 Chromium 多进程 IPC 架构、Blink 渲染管线、事件循环规范与性能指标底层机制，可随时点击顶部切换栏进入 核心原理篇 ↗。
