03.1 · 几何尺寸：CSS 标准盒模型与怪异盒模型（box-sizing）及三种隐藏方式对比

03.1 CSS 盒模型（Box Model）与元素隐藏方式辨析

在浏览器渲染引擎眼里，页面上的每一个 HTML 元素都是一个矩形盒子。由内向外，一个盒子由四层区域构成：内容区（content）→ 内边距（padding）→ 边框（border）→ 外边距（margin）。

当我们写下 width: 200px; padding: 20px; border: 2px solid #000; 时，这个元素在页面上实际占用的总宽度取决于 box-sizing 属性的设置：

浏览器默认值 · content-box 标准盒模型
width 仅代表最里层的「内容区宽度」

实际渲染总宽度 = width (200) + 左右 padding (40) + 左右 border (4) = 244px。在给元素加内边距或边框时，盒子会被撑大，容易把并排的布局挤换行。

工程全局推荐 · border-box IE / 边框盒模型
width 直接锁定「边框外沿总宽度」

实际渲染总宽度固定为 200px，内边距（40px）与边框（4px）向内挤压，内容区自动变为 156px。工程中通常在全局 CSS 顶部声明 *, *::before, *::after { box-sizing: border-box; }。

此外，日常开发中经常需要隐藏某个元素，三种常用 CSS 隐藏写法在布局占位、事件响应和渲染开销上有着本质区别：

CSS 隐藏属性 是否占据页面空间？ 能否触发点击事件？ 渲染表现与适用场景
display: none 否（完全移出布局流） 不能 该元素及其子元素根本不会生成布局盒，周围元素会填补其位置。切换时会引起周围元素重新计算位置（重排）。
visibility: hidden 是（保留原有空白占位） 不能 元素尺寸与位置保持不变，仅在绘制阶段跳过像素填充，不会引起周围元素移位。
opacity: 0 是（保留原有空白占位） 仍然可以触发点击 将整体不透明度设为 0（全透明），适合配合 transition 制作淡入淡出过渡动画；若需隐藏后禁止点击，需同时加上 pointer-events: none。
03.2 · 脚本加载与生命周期：script、defer、async、type="module" 与页面事件

03.2 四种脚本加载方式与 DOMContentLoaded / load 触发时机

当浏览器自上而下解析 HTML 文档遇到默认的 <script src="app.js"> 标签时，因为浏览器不知道这段脚本里会不会调用 document.write() 或读取修改 DOM，所以默认会暂停 HTML 解析，等待脚本下载并执行完毕后，再继续向下解析剩余的 HTML。如果把大体积脚本直接放在顶部 <head> 中，会导致页面长时间白屏。

为了不阻塞 HTML 解析，现代网页开发广泛使用 defer、async 或 ES 模块（type="module"）属性来控制脚本的下载与执行时机：

脚本标签写法 下载阶段是否阻塞 HTML 解析？ 执行时机与多个脚本顺序 日常工程适用场景
<script src="a.js"> 阻塞解析（停下等待下载并立即执行） 遇到即下载并执行，按在 HTML 中出现的先后顺序依次执行。 仅用于极少数必须在页面渲染前同步执行的初始化逻辑（通常放在 </body> 前）。
<script defer src="a.js"> 不阻塞（后台并行下载） 等整篇 HTML 解析完毕后、DOMContentLoaded 事件触发前，严格按书写顺序依次执行。 业务主脚本首选：既不阻塞 HTML 解析，又能保证此时完整 DOM 树已建立且多脚本按依赖顺序执行。
<script async src="a.js"> 不阻塞（后台并行下载） 谁先下载完就立刻插队执行谁（执行瞬间若 HTML 还没解析完会暂停解析），不保证执行顺序。 适合完全独立、不依赖页面其他脚本也不被依赖的第三方统计埋点或广告脚本。
<script type="module" src="a.js"> 不阻塞（后台并行下载模块及 import 依赖图） 默认自带 defer 延后执行行为，且自动启用严格模式与模块独立作用域。 现代工程化项目（如 Vite / 原生 ESM）的标准入口写法。
lifecycle_events.html · 推荐的 head 内 defer 脚本引入与两大页面生命周期事件 
<head>
  <link rel="stylesheet" href="./styles.css">
  <!-- 在 head 中使用 defer：浏览器一边解析 HTML 一边提前并行下载脚本，解析完再按顺序执行 -->
  <script defer src="./vendor.js"></script>
  <script defer src="./app.js"></script>
</head>
<body>
  <img id="hero-banner" src="./large-photo.jpg" width="800" height="400" alt="封面图">
  <script>
    // 1. DOMContentLoaded：HTML 文档完全解析完毕，且所有 defer 脚本执行完成后立刻触发（无需等待图片下载完）
    document.addEventListener('DOMContentLoaded', () => {
      console.log('1. DOM 树已就绪，可以安全绑定事件或初始化组件');
    });

    // 2. load：不仅 DOM 解析完，连页面上的所有图片、样式表、子框架等外部资源也全部加载完毕后才触发
    window.addEventListener('load', () => {
      console.log('2. 页面全部图片与静态资源均已加载完成');
    });
  </script>
</body>
