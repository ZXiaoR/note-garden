Node.js · 基础与实战篇

从开发环境安装、国内镜像配置与第一个可运行程序出发，依次梳理模块化与包管理、异步编程与事件驱动、文件系统与二进制流操作、HTTP 网络服务开发以及进程与工作线程的日常用法，最后通过一个完整的 Web 接口项目演示标准分层目录结构与单元测试。若需深入事件循环阶段、内存池切片与分代垃圾回收机制，可随时切换至 📘 核心原理篇 ↗。

② 文件流、HTTP 与进程
章节 03—05：path/fs 文件读写、Buffer 与 Stream 管道、HTTP 路由与进程/线程管理

00 · 认识 Node.js、环境安装与第一个程序：多版本管理（n / nvm / fnm / Volta）、国内镜像与内置模块全景

了解 Node.js 适用场景，掌握 `n / nvm / fnm / Volta` 版本管理与 `nrm` 镜像切换，运行第一个程序并一览全局对象与核心内置模块。

01 · 模块化与包管理日常用法：CommonJS、ES Module 与 package.json

掌握 `require / module.exports` 与 `import / export` 的日常写法、`node:` 协议前缀，以及 `package.json` 与 `npm / pnpm` 依赖管理。

02 · 异步编程与事件驱动基础：Promise、async/await 与 EventEmitter

梳理从错误优先回调到 `Promise.all` 并发组合与 `async/await` 的异步写法，以及 `EventEmitter` 事件监听与触发。

03 · 文件系统、路径处理与二进制流：path、fs/promises、Buffer 与 Stream

掌握跨平台路径拼接、异步文件读写与目录操作、`Buffer` 编码转换，以及用 `Stream` 与 `pipeline` 传输大文件。

04 · HTTP 网络服务与客户端请求开发：node:http 路由解析与原生 fetch

学会使用 `node:http` 搭建 Web 服务、解析 URL 参数与 JSON 请求体、设置状态码与响应头，并用原生 `fetch` 发起请求。

05 · 进程管理、环境变量与并发工具：process、child_process 与 worker_threads

掌握命令行参数与 `.env` 环境变量读取、优雅退出信号处理、调用外部子进程命令，以及启动 Worker 工作线程。

06 · 实际开发中 Node.js 项目怎么搭建与实战：分层目录结构、中间件与单元测试

从项目初始化开始，详解 `routes / controllers / services / middlewares` 标准分层目录，手写完整 HTTP JSON 服务与 `node --test` 单元测试。
