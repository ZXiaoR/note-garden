Node.js · 基础与实战篇：快速上手、Web 服务、七大业务场景与工程上线

面向熟悉前端 JavaScript、希望独立写出可上线后端服务的开发者与日常工程复习：从一屏看懂 Node.js 在后端架构中的定位与选型边界出发，五分钟用原生热重载和环境变量跑通第一个服务，依次掌握模块化、异步并发限流与取消、流式文件处理、Fastify 框架与参数校验，逐个落地数据库连接池、JWT 登录鉴权、大文件上传下载、大模型 SSE 流转发、第三方接口重试、定时任务队列与 CLI 七大高频业务场景，最后配齐 TypeScript 接入、结构化日志、Docker 优雅停机、线上排障速查与十道综合场景自测。

00 · 全景科普：Node.js 运行时定位、系统角色与选型边界

对比浏览器 JS 与 Node.js 的环境差异，一张图看懂 API、BFF、SSR、SSE 实时网关与 CLI 工具链五类角色，明确 CPU 密集短板与语言选型结论。

01 · 跑起来：版本管理、第一个服务与原生 --watch / --env-file

使用 nvm 安装 Node.js 24 / 26 LTS 并配置国内镜像，用内置 --watch 与 --env-file 跑起第一个服务，附其他版本工具与内置模块折叠速查表。

02 · 模块与包管理：CommonJS、ES Module 与 package.json

掌握 require / module.exports 与 import / export 日常写法、node: 协议前缀，以及 package.json 与 npm / pnpm 依赖锁定规范。

03 · 异步编程：Promise 编排、错误兜底、并发限流与超时取消

梳理 async/await 与四种 Promise 组合器，重点补齐未捕获 Promise 防崩兜底、最大并发数限制器、AbortController 取消机制与 EventEmitter。

04 · 文件与流：path 跨平台路径、fs/promises、Buffer 与 Stream 管道

掌握 import.meta.dirname 跨平台路径拼接、异步文件读写、Buffer 编码转换，以及用 Stream 与 pipeline 恒定低内存处理大文件。

05 · HTTP 服务：原生 node:http 原理、Fastify 框架、校验与跨域

保留原生 node:http 对照底层原理，用 Fastify v5 重写完整接口，给出四大主流框架选型表，落地 zod 参数校验、统一错误兜底与 CORS。

06 · 进程与线程：process 生命周期、child_process 与 worker_threads

掌握环境变量与优雅停机信号监听、安全调用外部子进程防命令注入，以及用 worker_threads 与 cluster 发挥多核 CPU 性能。

07 · 常见业务场景实战：按真实后端需求落地的七套方案

按「需求 → 方案 → 代码 → 坑 → 背后原理」逐个实现 MySQL 连接池与 Redis、JWT 登录鉴权、大文件流上传下载、SSE 大模型流转发与断连取消、第三方重试限流、定时任务队列与 CLI。

08 · 项目搭建与上线：分层目录、TypeScript、日志、Docker 部署与排障

详解四层工程目录、原生直跑 TypeScript 配置与 node --test 测试、环境变量启动校验、pino 脱敏日志、多阶段 Dockerfile 优雅停机及线上内存/CPU 排障速查。

09 · 场景自测：10 道真实线上排障与后端设计题

以默认折叠的真实线上问题检验重计算阻塞、2GB 上传 OOM、SSE 断连浪费、内存泄漏定位、发版 502、traceId 串号与连接池泄露等核心实战能力。
